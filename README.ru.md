# llmprobe — по-русски

Наведи на работающий локальный сервер инференса. Инструмент скажет, что этот
сервер **умеет на самом деле** — измеренно, а не по его собственным словам.

Полная документация — в [README.md](README.md). Здесь только то, ради чего всё
затевалось, и как этим пользоваться в CI.

## Зачем

`llama-server` сообщает, что держит 8192 токена контекста. Эндпоинт эмбеддингов
принимает документ на 2000 токенов и отвечает HTTP 200. Оба утверждения могут
быть правдой одновременно с тем, что последние 1500 токенов молча выброшены.

Это не гипотеза. При включённых эмбеддингах llama.cpp зажимает физический батч
до `n_ubatch` (по умолчанию **512**), а pooled-эмбеддинг обязан уместить всю
последовательность в один физический батч. Всё, что выше 512 токенов, либо
падает, либо обрезается. При этом `n_ubatch` **не отдаётся по HTTP вообще** —
его нет в `/props`. Прочитать нельзя. Можно только измерить.

Именно так 26 документов из 30 не проиндексировались в RAG-конвейере, и каждый
запрос при этом возвращал успешный код.

## Как гейт в CI

Коды возврата: `0` — чисто, `1` — заявленная ёмкость не совпала с измеренной,
`2` — ошибка. Это и делает инструмент гейтом, а не разовым отчётом.

```yaml
- name: Проверить реальную ёмкость сервера
  run: |
    pip install git+https://github.com/botAGI/llmprobe
    llmprobe http://localhost:8080 --probe --claimed-ctx 8192
```

Гейт краснеет, когда бамп образа тихо срезал ёмкость, — то есть ловит регрессию
там, где сервер продолжает отвечать 200 и выглядеть здоровым.

## Что проверено вживую

| Бэкенд | Чтение конфига | Замер ёмкости |
| --- | --- | --- |
| llama.cpp | живьём | **живьём, в обе стороны** |
| vLLM | живьём | живьём |
| Ollama | только моки | только моки |
| generic OpenAI-совместимый | только моки | только моки |

Пара контрольных серверов поднимается скриптом `scripts/live_control.sh`:
один с дефолтным `n_ubatch` (инструмент обязан найти обрыв), второй с
`-b/-ub 8192` (обязан промолчать). Детектор, который срабатывает всегда,
провалит второй; который не срабатывает никогда — первый.
